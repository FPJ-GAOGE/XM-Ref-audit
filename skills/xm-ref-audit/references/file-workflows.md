# 文件读写与最终验证

## 通用

优先编辑可维护的原始引用数据，再通过原有引用引擎生成显示。始终保留输入副本和原始条目；建立完整母库（BibTeX/BibLaTeX、CSL-JSON 或既有数据库格式），不要为了缩短输出永久删除字段。使用成熟解析器处理 BibTeX 的嵌套括号、宏、重音字符、字符串拼接、crossref/xdata；正则只能用于候选发现，不能据此声称完整解析。

母库与审计记录以稳定条目 ID 关联；文中每处引用设 occurrence ID。记录原编号/键和新编号/键映射。渲染后复查所有改号位置，包括表格、图注、附录、脚注、链接与交叉引用。只格式修正时正文内容应保持不变；语义修订另列。

## Word：.docx / .doc

- 查看文内引用是纯文本、Word 内建字段还是 Zotero/EndNote/Mendeley 的字段/内容控件。读取段落、表格、脚注、尾注及相关 OOXML 部件，不能只读 `document.paragraphs`。检查超链接和文本框中的引用。
- 对引用管理器字段优先用原引擎/库更新并刷新。仅改显示文字会在刷新时丢失；不支持该引擎时保留字段，提供母库修正和应用说明，明确无法完成自动回写部分。
- 纯文本参考文献可以用 python-docx 或 OOXML 做局部替换，保留段落样式、悬挂缩进、斜体、超链接、上标等。避免用 `paragraph.text = ...` 无差别重建整段而损坏其他结构。
- `.doc` 先用可信办公软件转换成新的 `.docx`，不运行宏；转换后核对内容和版面。
- 用 Word 或 LibreOffice/可用文档渲染器导出 PDF，实际检查变化页、参考文献分页及总页数。OOXML 的缓存页数、词数推算和换页符数量均不能作为最终页数。无渲染器则明确“版面/页数未验证”。

## PDF：文本型与扫描型

- 用可靠 PDF 工具提取带页码的文字与布局，检查双栏顺序、连字符、上下标、链接、页脚；必要时查看逐页图像。扫描件 OCR 后复核作者、DOI、年份、卷期页码等关键字段，不把 OCR 结果当权威来源。
- 有 Word/LaTeX 源时修改源文件并重新导出。只有 PDF 时先完成全文引用映射和真实性审计，生成修正后的参考文献表、结构化母库，以及逐页定位的批注/修订建议 PDF。
- 若版面适合且能可靠重排，可以在新副本上修改文献区并校验正文未被遮挡；需重排或改号而无法可靠保持全文映射时，不用白块盖字冒充最终修正版。交付有清晰标签的批注版与可编辑参考文献，不宣称原 PDF 已全部修好。
- 只有参考文献页而无正文时，可核查条目身份与格式，正文支持关系状态必须为待核查。需要正文才能完成逐处论断检查。

## LaTeX：.tex / .bib / .bbl

- 首先读取并执行 [网站引用取回流程](latex-retrieval.md)，取回官方导出数据并核对字段。自动修复包括“检索 → 下载/导出 → 身份核对 → 保留键合并 → 编译验证”，不止本地格式整理。
- 识别主文件、include/input、bibliography/addbibresource、thebibliography、BibTeX/Biber、bst/bbx/cbx 及引用宏。只在项目授权目录内解析依赖；不要执行源文件中的外部命令或默认开启 shell escape。
- `.bib` 作为首选修改源，保持引用键。根据样式采用 `journal`/`journaltitle`、`year`/`date`、`pages`/`eid` 等实际支持字段；不要把 Biber 字段机械写入不支持的 BibTeX 流程。
- BibTeX 作者以 `and` 分隔，机构作者用适当括号保护。页码范围使用 `--`；局部保护缩略词和专有名词，处理 TeX 特殊字符而不破坏数学表达式。不能靠全量 lower/title-case 改标题。
- 优先使用样式正式选项切换显示密度，不全局篡改安装目录下的 `.bst`。若必须定制，把副本放项目并检查投稿规则。
- 避免只改下次编译会覆盖的 `.bbl`；仅有 `.bbl` 或手写 `thebibliography` 时可编辑副本并说明来源限制。
- 在隔离输出目录按项目实际引擎运行完整文献编译链或 latexmk；禁用 shell escape，检查缺失键、重键、未定义引用、编译错误、BibTeX/Biber 警告，并检查最终 PDF 页数与参考文献页面。编译成功不等于引用事实正确。

## 其他来源

Markdown、HTML、纯文本、ODT 等采用相同身份/证据模型，遵循已有引文处理器和样式。不能因为文件更简单就减少真实性核查。缺少可恢复结构时明确所能检查的范围。
