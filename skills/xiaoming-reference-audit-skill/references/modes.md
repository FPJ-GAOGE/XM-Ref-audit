# 三档引用与页数预算（用户扩展）

三档控制显示密度；所有档位共用完整、已核实的母库，并执行相同强度的真实性核查。目标刊物或学校的强制样式优先，不能称违反投稿要求的极简版为合规版。

| 项目 | 极简 minimal | 常规 regular | 详细 detailed |
| --- | --- | --- | --- |
| 作者 | 样式允许的姓名缩写、作者截断 | 样式默认作者规则 | 样式允许时列全作者/较完整姓名 |
| 题名 | 保留完整题名；只有明确投稿规范允许省略时才省略 | 完整题名 | 完整题名及必要的版本区分 |
| 出版源 | 可核实的标准简称 | 样式默认全称或简称 | 样式允许的全称 |
| 年份、卷期、页码或文章编号 | 保留所有必要定位字段 | 完整必要定位字段 | 完整必要定位字段 |
| DOI/稳定 URL | 样式必需、无其他足够定位信息或在线资源才显示；母库始终保存 | 样式允许且存在时显示 DOI 或稳定 URL，避免重复 | 样式允许时保留 DOI 及有独立用途的链接 |
| 出版社/出版地/会址/日期/版次 | 保留类型或样式必需项 | 按模板默认 | 添加确有信息价值且模板允许的字段 |
| 访问日期 | 动态网页或样式要求时保留 | 同左 | 同左，不伪造访问时间 |

详细不表示加摘要、评价或全文引文。各档不能把文章编号伪造为页码、把缺失年份填为推测年份，或省略文献身份所必需的信息。每项允许压缩与否都应在本次目标样式下核实。无外部样式时上述表为本 skill 的默认呈现规则。

## 自动选择

1. 用户明确指定档位时采用该档，仍检查页数和模板；不合规或超限要报告冲突，不能静默切档。
2. 无页数上限、参考文献明确不计入上限或缺少可用渲染器时，默认常规，除非用户要求详细。参考文献不计页数时仍检查正文是否超限；缩短参考文献不能解决正文超限。页数未知时把选择标为暂定。
3. 有包含参考文献的总页数预算时，在相同字号、页边距、单双栏、图片和正文条件下，优先渲染详细；若超限再渲染常规、极简，选择合规且能放下的最详细档位。可以提前测完三档再比较。不能用“6 页以内极简、10 页以上详细”等虚构通用阈值。
4. 若所有允许档位均超限，输出最简合规版本与超出页数，交由用户决定是否修改正文；不得删必要引用或绕过模板字号与间距。
5. 数据补全可能使文献变长；必须对最终修正版再计页。只提供 PDF 时使用原 PDF 的实际页数，但没有可控源文件时，不能据此假装已测出修改后三档页数。

## 脚本输入

`scripts/select_mode.py` 接受 UTF-8 JSON。`measurements` 是最终修正版按每档真实渲染后得到的计数，禁止放估算值。

```json
{
  "requested_mode": "auto",
  "page_limit": 8,
  "references_counted": true,
  "allowed_modes": ["minimal", "regular", "detailed"],
  "measurements": {"minimal": 7, "regular": 8, "detailed": 9}
}
```

字段：`requested_mode` 为 auto/minimal/regular/detailed；`page_limit` 为正整数或 null；`references_counted` 为 true/false/null（未知）；`allowed_modes` 由本次模板实际允许的档位组成。若参考文献不计页数，可提供独立渲染/统计得到的 `body_pages`。未测量的档位不要填值。脚本在潜在更详细可行档位未测时返回 `needs_measurement`，防止把暂定方案当作最终结果。
